Disease Predictor AI reads lab reports (PNG, JPG, PDF), flags abnormal values, predicts possible conditions and suggests healthy-living tips.

Try it now

01 Problem statement

Lab reports are full of numbers and medical terms that most patients cannot interpret, so early warning signs are missed and people panic or ignore results. This project turns a report image or PDF into plain-language findings, possible conditions with a confidence level, and condition-specific lifestyle and diet tips, in Hinglish, Hindi or English.

Scope: awareness and education only. It does not diagnose, and every result tells the user when to consult a doctor.

    03 How it works

    1. UploadThe browser shrinks large images, then sends the file over HTTPS. Files are checked by real file signature and never stored.
    2. AnalyzeThe Express server sends the file to a multimodal AI model with a structured prompt.
    3. ValidateThe JSON answer is strictly validated and bounded before it reaches the browser.
    4. RenderFindings, predictions, tips and diet are shown as an accessible report you can print or export.
